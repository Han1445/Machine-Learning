This lab task applies linear regression to predict yearly customer spending for an e-commerce platform based on user engagement metrics.



Key Steps:



Data Loading \& Cleaning: Loaded Ecommerce Customers.csv using Pandas, checked for missing values and duplicates, and formatted address text.



Feature Engineering: Combined app and website usage time into a single Total Time Spent feature.



Data Preparation: Split the dataset into 70% training and 30% testing subsets using scikit-learn.



Model Training: Trained a Linear Regression model on the training data.



Evaluation: Evaluated performance using MAE, MSE, RMSE, and the R-squared score, and plotted actual vs. predicted spending values.
